# Error Taxonomy

Use the narrowest applicable type. Multiple types may be attached when one finding genuinely spans categories.

| Type | Definition | Typical signal |
|---|---|---|
| LOGIC_ERROR | Research reasoning does not follow from stated premises/evidence | conclusion does not follow |
| METHODOLOGY_ERROR | Design/procedure may not support the research question or stated inference | causal question with weak design |
| EVIDENCE_ERROR | Evidence does not adequately support a material claim | source supports association, claim says cause |
| CITATION_ERROR | Citation is missing, mismatched, or cannot be traced | cited source not tied to claim |
| STATISTICAL_ERROR | Reported statistical interpretation is inconsistent with stated statistic | p-value misinterpreted |
| DATA_ERROR | Dataset/report contains a supported data-level inconsistency | impossible coding, unexplained N |
| CONSISTENCY_ERROR | Same entity/fact differs across sections without explanation | N=300 vs N=287 |
| SCOPE_ERROR | Claim exceeds population, sample, context, period, or design | local sample → all people |
| CAUSALITY_ERROR | Causal language exceeds identification/design/evidence | correlation → causes |
| DEFINITION_ERROR | Construct/variable meaning changes without explanation | adoption → usage |
| ALIGNMENT_ERROR | Two research components are not mapped or answered | RQ has no objective |
| DEPENDENCY_ERROR | Change or removal leaves downstream components inconsistent | removed hypothesis still appears in conclusion |
| COMPLETENESS_ERROR | Required project information is absent for a material decision | sample procedure missing |
| TRACEABILITY_ERROR | A claim/decision/result cannot be traced to source/evidence | unsupported decision rationale |

## Naming rule

Do not create a new error type merely because an existing type is inconvenient. Prefer the taxonomy above and explain secondary dimensions in the reasoning.
